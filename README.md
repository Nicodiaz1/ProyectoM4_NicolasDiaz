# Proyecto M4 — Modelos de Machine Learning

Desarrollo de modelos predictivos sobre datos de crédito, cubriendo aprendizaje
supervisado y no supervisado, con evaluación comparativa de desempeño.

## Notebooks
1. `1.Notebooks/1_EDA_RegresionLogistica.ipynb` — análisis exploratorio + regresión logística (baseline).
2. `1.Notebooks/2_GradientBoosting_Optimizacion.ipynb` — Gradient Boosting con optimización de hiperparámetros.
3. `1.Notebooks/3_AprendizajeNoSupervisado.ipynb` — clustering / segmentación.

## Documentación
- `2.Documentacion/Reporte_Modelos.pdf` — informe de resultados y conclusiones.

## Tecnologías
Python · scikit-learn · pandas · Jupyter
